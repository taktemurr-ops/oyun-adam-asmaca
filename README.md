# Yaprak Tahmini · Petal Guess

Yapraklar dökülmeden kelimeyi bul!

Klavyeden harf seç. Harf kelimede varsa her yerde açılır; yoksa çiçekten bir yaprak düşer. Bütün yapraklar düşmeden kelimeyi tamamla.

100.000 bölüm; her bölüm üretilir ve kurallara göre doğrulanır. Kelime Oyunları merkez uygulamasının oyunu; ortak motor: [kelime-motoru](https://github.com/taktemurr-ops/kelime-motoru).
